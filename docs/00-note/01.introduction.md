# Goclaw Explained: Scaling AI Agents from Prototype to Production 
## What make AI Agent Scaling hard 
 Các ngôn ngữ như Python đươc thiết kế với tính tiện dụng, tuy nhiên khó bao quát hết tất cả trường hợp lỗi (kiểm soát lỗi không chặt ché) 

 Khi lên môi trường Production dễ dẫn đến hư hại hệ thống. 


### Folder structure 
Process Composition: 
| Runtime responsibility | Project package | Role |
|---|---| --- | 
| Process composition | `internal/app` | Quản lý các thành phần của hệ thống | 
| Agent execution | `internal/agent` | Quản lý và xử lý một agent run. Từ khi người dùng gửi request cho đến khi có dduowqjc output hoàn chỉnh |  
| Provider-neutral types | `internal/model` | Các KDL chung, đóng vai trò là nơi tương tác giữa system và AI provider. Nếu không có nó, hệ thống agent sẽ gắn chặt vào 1 format JSON của một AI provider | 
| Tool execution and policy | `internal/tools` | Danh sách các file tools và quản lý store | 
| Session persistence | `internal/session`, `internal/store/postgres` | Store and manage user's session | 
| Queue and events | `internal/runtime` | 
| HTTP and WebSocket | `internal/transport` | Sử dụng HTTP để lấy một số dữ liệu cần thiết, một chiều từ phía agent server, ví dụ: Dữ liệu đã hoàn thành, tạo / cập nhật resource. Health check, gửi message và một response hoàn chỉnh. Ngược lại, web socket dùng cho các tác vụ thời gian thật: realtime, streaming câu trả lời, theo dõi một agent run đang chạy.
