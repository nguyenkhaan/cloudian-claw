# AI Agents 

AI Agent consists of: 
- Model (LLM): brain of the agent, models like gpt-5 or sonet-4 are what powers the agent and give it the ability to think, this is the most important component 
- Context: information the model has access to the respond, your query plus any related information needed to resolve the query 
- Tools: functions we can call for the model and give the model the result, the model can decide when it need to call
